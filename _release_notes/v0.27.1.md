# czitools v0.27.1

Released: 2026-10-29

This release adds opt-in preservation of the original CZI XML when converting
images and HCS plates to OME-Zarr. Existing exports remain unchanged unless
the option is enabled.

## Added

- Python 3.14 support alongside Python 3.12 and 3.13, with all three
  versions included in the Windows, Linux, and macOS CI test matrices.
- All four conversion APIs accept `preserve_original_metadata=True`:
  `write_omezarr`, `write_omezarr_ngff`, `convert_czi2hcs_omezarr`, and
  `convert_czi2hcs_ngff`.
- Conversion scripts and the benchmark accept
  `--preserve-original-metadata` for both writing backends.
- The standalone and napari-embedded converter GUI offer an unchecked
  **Preserve original CZI XML** checkbox.
- Directory stores and supported `.ozx` archives embed the source reader's
  raw XML text as UTF-8 at `CZI/metadata.xml`, without parsing or
  reserializing it. Root `czitools.originalMetadata` attributes reference
  the object and record its format, media type, and source filename.
- Regression coverage includes both backends, images and plates,
  enabled/disabled behavior, archive layout and failure cleanup, GUI and
  script forwarding, and exact XML round trips from a real CZI file.

## Compatibility and Storage

- Preservation defaults to `False` in Python, scripts, and the GUI.
- The XML location and reference are a documented czitools convention,
  not a standardized OME-NGFF field or an RFC-8 extension.
- Vendor CZI XML is not OME-XML. `OME/METADATA.ome.xml` remains reserved
  for genuine OME-XML and is not written by this feature.
- A plate stores one copy of the complete source XML, not one per field.
  Binary attachments and per-subblock metadata are not copied.
- The original CZI must remain readable when preservation is enabled.
  Missing or unreadable XML fails the conversion rather than silently
  omitting the document.
- Opted-in `.ozx` exports stage a directory beside the destination before
  archive creation. Allow space for both the staging store and final
  archive, plus any pyramid caches. Temporary metadata staging is removed
  on success or failure.
- Preserved XML may contain acquisition or user information; review it
  before sharing an export.

## Example

```python
from czitools.export_tools import convert_czi2hcs_ngff

output = convert_czi2hcs_ngff(
    "plate.czi",
    preserve_original_metadata=True,
)
```

## Upgrade

```bash
python -m pip install --upgrade "czitools[omezarr-gui]==0.27.1"
```

Python 3.12, 3.13, and 3.14 are supported.
