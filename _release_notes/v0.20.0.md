# v0.20.0

**Release Date:** 2026-07-30

## Highlights

- **First-class CZI well-plate support** — CZI metadata can now be interpreted
  as an immutable Plate → Well → Field hierarchy with normalized well lookup,
  field resolution, HCS detection status, and opt-in stage-position enrichment.
- **OME-Zarr HCS export** — Well-plate CZI files can be written as OME-NGFF HCS
  layouts using either the ngff-zarr or ome-zarr-py backend and validated after
  conversion.
- **Reliable large-file access** — Scene-wise readers provide genuinely lazy
  Dask arrays, stable list/stacked return contracts, and support for unequal
  scene shapes.
- **Optional analysis and GUI layers** — New extras provide a converter GUI,
  HCS object analysis, and well-plate heatmaps without burdening the core
  installation.

## Added

### HCS metadata model

- `src/czitools/metadata_tools/hcs.py`
  - Added immutable `CziPlate`, `CziWell`, and `CziField` models.
  - Added explicit HCS detection results and explanatory failure reasons.
  - Added normalized lookup for well names such as `B4`, `b04`, and `B/4`.
  - Added well-local field resolution by index or source `RegionId`.
  - Added absolute and well-relative field-position helpers.
  - Added opt-in planetable enrichment for subblock stage/focus coordinates,
    ranges, source information, and conflict flags.
- `src/czitools/metadata_tools/czi_metadata.py`
  - Added `hcs`, `hcs_status`, and `enrich_hcs_positions()`.

### Pixel readers

- `src/czitools/read_tools/read_tools.py`
  - Added `read_field()` and `read_well()` for HCS-aware pixel access.
  - Added `read_stacks_list()` and `read_stacks_stacked()` for explicit,
    type-stable scene-wise return contracts.
  - Extended `read_stacks()` with true lazy Dask plane reads, optional scene
    stacking, plane selection, zoom handling, and chunk policies.
- `src/czitools/read_tools/__init__.py`
  - Exported the new public reader functions.

### OME-Zarr export

- `src/czitools/export_tools/`
  - Added lazy public imports with actionable optional-dependency errors.
  - Added canonical HCS layout resolution.
  - Added `convert_czi2hcs_ngff()` for OME-NGFF v0.5/Zarr v3 output.
  - Added `convert_czi2hcs_omezarr()` with Zarr v3 output by default and a
    legacy OME-NGFF v0.4/Zarr v2 option.
  - Added single-image OME-Zarr writers, validation, display helpers,
    compression controls, normalized pyramid paths, and logging.
  - Added a MagicGUI/napari converter application and the
    `czitools-omezarr-gui` console command.

### Analysis

- `src/czitools/analysis_tools/`
  - Added `ArrayProcessor` thresholding and object-labeling helpers.
  - Added HCS OME-Zarr processing across wells and fields.
  - Added well-plate heatmap visualization.

### Tests and examples

- Added focused tests for HCS detection and traversal, sample metadata,
  well/field reads, export tools, and analysis tools.
- Added scripts demonstrating HCS models, field reads, stage-position
  enrichment, non-plate fallback behavior, HCS conversion, validation,
  benchmarking, and GUI launch.
- Added notebooks for reading CZI well plates and processing OME-Zarr HCS data.

## Changed

- `src/czitools/metadata_tools/sample.py`
  - Per-scene collections now retain one entry per scene.
  - `field_centerX` and `field_centerY` preserve valid `0.0` coordinates and
    use `None` for absent or malformed scene-center metadata.
  - Added region IDs and clearer scene-count versus unique-well semantics.
- `src/czitools/read_tools/read_tools.py`
  - Clarified that `read_6darray(use_dask=True)` is Dask-backed but eagerly
    reads the CZI; `read_stacks(use_dask=True)` is the true lazy path.
  - Extended scene-wise reads to optional CZI dimensions while retaining
    canonical dimension ordering.
- `pyproject.toml`
  - Added `omezarr`, `omezarr-gui`, `analysis`, and expanded `all` extras.
  - Added explicit Dask and modern `czifile` requirements.
  - Updated project description and documentation URL.
- `pixi.toml` / `pixi.lock`
  - Added `imagecodecs>=2026.6.6` from conda-forge and
    `czifile>=2026.6.6` from PyPI to keep compiled codecs compatible.
- `README.md`, `docs/install.md`, and `docs/usage.md`
  - Documented eager and lazy reader selection, general CZI metadata,
    well-plate metadata, HCS conversion, validation, and end-to-end examples.

## Fixed

- Correctly distinguish missing scene-center coordinates from real `0.0`
  coordinates.
- Preserve ordinary metadata and pixel access when HCS detection fails.
- Support HCS conversion when fields or scenes have unequal shapes.
- Normalize sparse plate row/column indices for spec-compliant readers.
- Normalize multiscale level paths for OME-NGFF/IDR interoperability.
- Restrict TestPyPI publication to `testpypi-v*` tag builds.
- Resolve the Pixi `imagecodecs`/`czifile` dependency conflict.
- Declare Requests, Zarr, and Matplotlib as runtime dependencies required by
  the public core import path.
- Remove stale imports and fix correctness-focused lint errors.

## Compatibility notes

- Python 3.12 and 3.13 are supported.
- HCS is an additional metadata interpretation; non-plate and ambiguous files
  remain readable through the general CZI APIs.
- `scene_stageX` and `scene_stageY` remain compatibility properties but cannot
  distinguish missing coordinates from `0.0`; use `field_centerX` and
  `field_centerY`.
- OME-Zarr export and validation require `pip install "czitools[omezarr]"`.
- HCS analysis requires `pip install "czitools[analysis]"`.
- The GUI requires `pip install "czitools[omezarr-gui]"`.

## Upgrade

pip install --upgrade "czitools==0.20.0"
