# v0.20.1

**Release Date:** 2026-08-02

## Highlights

- **Reliable nested HCS exports** — New output directories are created before
  conversion logging starts, and ngff-zarr compression options are sent to the
  correct writer argument.
- **Lighter package startup** — Public subpackages load only when accessed,
  keeping optional visualization dependencies out of basic imports.
- **Notebook-friendly napari integration** — Display helpers can return a live
  viewer without starting napari's blocking event loop.

## Added

- `src/czitools/_tests/test_export_tools.py`
  - Added coverage for HCS conversion into a previously absent nested output
    directory.
  - Added a local ngff-zarr writer regression test that verifies compression is
    not forwarded as an FSSpec storage option.
- `src/czitools/_tests/test_lazy_package_imports.py`
  - Added a subprocess regression test for lazy public subpackage imports.
- `demo/notebooks/czitools_usage_demo.ipynb`
  - Added a consolidated workflow covering metadata, pixel reading, napari,
    HCS, and OME-Zarr usage.
- `demo/scripts/napari_czi_omezarr_gui.py`
  - Added a small script for launching the converter widget inside napari.

## Changed

- `src/czitools/__init__.py`
  - Replaced eager public subpackage imports with `__getattr__`-based lazy
    loading while preserving interactive discovery through `__dir__`.
- `src/czitools/utils/napari_tools.py`
  - `display_xarray_in_napari()` and `display_xarray_list_in_napari()` now
    return their viewer and accept `run=False` for notebook workflows.
- `pyproject.toml`
  - Declared NumPy and validators as direct core dependencies.
  - Replaced the unused `colormap` dependency with `cmap`, consolidated
    ngff-zarr extras, retained tensorstore for OME-Zarr writing, and removed
    duplicate optional requirements and stale embedded Pixi configuration.
- `pixi.toml` / `pixi.lock`
  - Selected PyQt6 explicitly for Windows and Linux without pulling the Linux
    conda Qt/GLX stack.
  - Added `cmap` and tensorstore, removed the incompatible unused `colormap`
    package, and added a Qt-backend verification task.
- `README.md`, `.github/copilot-instructions.md`, and `docs/usage.md`
  - Updated installation, lazy-reading, HCS, OME-Zarr, GUI, notebook, and
    contributor guidance to match the current APIs.
- `demo/notebooks/`
  - Refreshed metadata, pixel-data, and well-plate examples and outputs.

## Fixed

- `src/czitools/export_tools/_logging.py`
  - Creates the parent directory of the conversion log before constructing its
    file handler, fixing HCS conversion to new nested output directories.
- `src/czitools/export_tools/conversion.py`
  - Passes compression via ngff-zarr's `compressor` argument instead of an
    invalid `storage_options` entry.
- `src/czitools/export_tools/gui.py`
  - Selects the PyQt6 backend before QtPy and MagicGUI are imported.

## Compatibility notes

- Python 3.12 and 3.13 remain supported.
- The published package retains `pylibCZIrw>=5` compatibility; the development
  workspace tests against the current major release.

## Upgrade

```bash
pip install --upgrade "czitools==0.20.1"
```
