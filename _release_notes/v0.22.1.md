# czitools v0.22.1

Release date: 2026-08-27

## Highlights

- Handles CZI files with missing or partial microscope metadata without
  raising `AttributeError`.
- Constrains regular 6D reads to non-pyramid layer-0 bounds, preventing padded
  pyramid coverage from producing incompatible array shapes.
- Includes maintenance cleanup of legacy code and supporting tests.

## Microscope metadata

`CziMicroscope` now checks each nested metadata node before reading `Id`,
`Name`, and `System`. Missing values remain `None`, matching the behavior of
other optional metadata classes. This fixes files such as
`Sandstone_Raw-HR-NLM.czi`, where `Instrument` exists but `Microscopes` is
absent.

## Compatibility

- Python 3.12 and 3.13
- No intentional breaking API changes

## Installation

```bash
python -m pip install --upgrade "czitools==0.22.1"
```

## Validation

- The instrument metadata test module passes.
- Full metadata construction was verified with the affected Sandstone CZI.
