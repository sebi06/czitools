# czitools v0.23.1

Release date: 2026-08-31

## Highlights

- **ngff-zarr 0.45 support**: Updated the optional dependency floor and migrated
  exports to the always-on zarrista backend.
- **Simplified storage configuration**: Removed the obsolete TensorStore
  dependency, writer argument, and converter GUI option.
- **ome-zarr compatibility retained**: The independent `ome-zarr-py` export
  backend and direct `zarr` dependency remain supported.

## Compatibility

- Python 3.12 and 3.13
- ngff-zarr >= 0.45.0
- ome-zarr >= 0.18.0
- No intentional breaking API changes outside removal of the ineffective
  TensorStore option

## Installation

```bash
python -m pip install --upgrade "czitools==0.23.1"
```

## Validation

- Full czitools test suite passes in the Pixi workspace
- Regression coverage confirms the removed writer argument and GUI control do
  not return
