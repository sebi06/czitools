# czitools v0.25.1

## Fixes

- Removed the unused `ngff-zarr[cli]` dependency set from the `[omezarr]` and
  `[omezarr-gui]` extras. Its `imagecodecs` upper bound conflicted with the
  version required by `czifile`, preventing pip from resolving these extras.
- Added a modern `colorlog` minimum version so resolver backtracking cannot
  mask dependency conflicts with failures from obsolete source distributions.

## Installation

Upgrade the OME-Zarr GUI installation:

```bash
python -m pip install --upgrade "czitools[omezarr-gui]"
```

Or upgrade the OME-Zarr export dependencies without the GUI:

```bash
python -m pip install --upgrade "czitools[omezarr]"
```
