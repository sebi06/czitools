# czitools v0.27.3

Released: 2026-11-06

This release adds reference-backed CZI VZIP archives and optional
pyramid-subblock information in plane tables.

## Added

- `create_czi_vzip` saves a local CZI's virtual OME-Zarr hierarchy as a
  `.vzip` archive without copying or converting image pixels. It returns
  an absolute `Path`, defaults to a sibling archive, and protects existing
  archives unless `overwrite=True` is supplied.
- The optional `czitools[vzip]` extra installs `refkv[zarr,images]>=0.2.0`.
  Archive creation imports refkv lazily and requires neither napari nor Qt.
- Repository examples create archives and display the first resolution
  level of each image series lazily in napari, with channel names and
  spatial scaling. The viewer example requires napari and a Qt backend;
  it is not a multiscale viewer or a reader plugin.
- `get_planetable(..., include_pyramid=True)` includes stored image-pyramid
  subblocks and adds `is_pyramid`, `stored_width`, `stored_height`,
  `downsample_x`, and `downsample_y`. Downsampling factors are logical
  dimensions divided by stored dimensions, independently for X and Y.
- Plane filtering, empty results, and CSV saving retain the extra columns.
  Regression tests cover VZIP creation and pyramid-inclusive plane tables.
- Updated README Highlights and installation and usage documentation.

## Compatibility

- VZIP archives contain metadata and references, not standalone pixel
  exports. Keep the original CZI unchanged at its original location.
  Supported layouts and codecs are determined by refkv.
- Plane tables still exclude pyramid subblocks by default, with the
  existing columns and full-resolution behavior preserved.
- Bounding boxes remain in full-resolution pixel coordinates. Tile indices
  are counted independently per resolution and do not identify matching
  source tiles across pyramid levels. Non-positive spatial dimensions
  raise `ValueError` in the opt-in mode.
- Python 3.12, 3.13, and 3.14 remain supported.

## Example

```python
from czitools.export_tools import create_czi_vzip
from czitools.utils import planetable

archive = create_czi_vzip("image.czi")
table, _ = planetable.get_planetable("image.czi", include_pyramid=True)
pyramid_rows = table[table["is_pyramid"]]
```

## Upgrade

For plane tables and core reading, upgrade `czitools` normally. To also
enable VZIP creation:

```bash
python -m pip install --upgrade "czitools[vzip]==0.27.3"
```
