# Release Notes: v0.22.0

**Release Date:** August 25, 2026

---

## Overview

v0.22.0 introduces a powerful command-line interface for inspecting High-Content Screening (HCS) well plates, improves robustness of scene shape handling, and delivers enhanced code quality through linting compliance and circular import fixes.

---

## New Features

### CZI HCS Inspector Tool (`czi_hcs_check`)

A new CLI utility for viewing and analyzing High-Content Screening (HCS) well plates in CZI files:

```bash
czi_hcs_check --file <path_to_czi> [--well <well_id>] [--no-well-table]
```

**Features:**
- **Plate Overview**: Displays comprehensive HCS plate information including plate format, number of scenes, and well layout
- **Well Inspection**: View detailed information for specific wells (e.g., `--well B5`)
- **Sample Metadata**: Shows sample metadata, first scene details, and well-specific filtering
- **Field Details**: Lists all fields/scenes within a well with their positions and dimensions
- **Rich Formatting**: Uses colored terminal output with formatted tables and panels for readability

**Example Usage:**
```bash
# View entire plate structure
czi_hcs_check --file WP96_plate.czi

# Inspect specific well
czi_hcs_check --file WP96_plate.czi --well B5

# Skip well summary table
czi_hcs_check --file WP96_plate.czi --no-well-table
```

**Implementation:**
- New module: `czitools.utils.hcs_tools` provides display utilities for HCS metadata
- New script: `demo/scripts/czi_hcs_check.py` entry point
- Built on `czitools` metadata infrastructure with `rich` formatting
- Comprehensive documentation in [docs/usage.md](../docs/usage.md)

---

## Improvements

### Scene Shape Tolerance

- Improved tolerance when scene shapes differ by only a few pixels (e.g., rounding errors across multiple scenes). The reader now handles minor dimension mismatches gracefully instead of failing or producing inconsistent arrays.

### Pyramid Level Checking

- Fixed issue with pyramid level enumeration. The check for stored pyramid levels in CZI files now correctly identifies and validates all available zoom levels via `pylibCZIrw.CziReader.enumerate_subblocks`.

---

## Bug Fixes

### Code Quality

- **Fixed circular imports**: Resolved circular dependency between `hcs_tools` and `metadata_tools` modules using Python's standard `TYPE_CHECKING` pattern (PEP 484/563)
- **Ruff linting compliance**: Fixed all static analysis violations (F821 undefined names, F541 f-string placeholders) to maintain code cleanliness
- All 343 tests continue to pass; no functionality regressions

---

## Technical Details

### Module Refactoring

The solution to circular imports demonstrates best practices:
- Uses `from __future__ import annotations` for deferred type evaluation
- Wraps metadata_tools import in `if TYPE_CHECKING:` guard
- Import is visible to static analyzers but prevented at runtime
- Standard Python pattern that satisfies both linting and functional requirements

### Compatibility

- Python 3.12, 3.13
- All dependencies unchanged from v0.21.1
- Backward compatible: no breaking changes to existing APIs
