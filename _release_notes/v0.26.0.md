# czitools v0.26.0

## Added

- HCS NGFF conversion supports explicit OME-NGFF v0.6 output in addition to
  the v0.5 default.
- HCS conversion exposes configurable pyramid levels, spatial chunking,
  sharding, and bounded field concurrency across generated levels.
- The OME-Zarr GUI reports HCS backend policy, individual scene dimensions,
  conversion progress, and selected output layout.

## Changed

- The GUI uses the **Quality** conversion preset by default while retaining
  **Fast balanced** for non-HCS NGFF exports.
- HCS conversion reuses stored CZI pyramid levels where available and applies
  suitable chunking and sharding to spatial and 3D data.
- The full and documentation extras now use an `ngff-zarr>=0.47.0` dependency
  floor.

## Fixed

- OME-NGFF v0.6 HCS validation dispatches plate stores to
  `ngff_zarr.from_hcs_zarr()` instead of the image reader.
- The GUI no longer exposes a confusing nullable compression placeholder.
- HCS logging includes individual scene dimensions and the selected layout.

## Upgrade

```bash
python -m pip install --upgrade "czitools[omezarr-gui]"
```
