# czitools v0.25.0

## Highlights

- Added the packaged `czi_hcs_check` command for inspecting CZI HCS metadata,
  physical dimensions, bounds, and valid indices.
- Reconciled the default HCS model with fields physically stored in layer-0
  subblocks while preserving the complete XML acquisition model through
  `hcs_declared` and `filter_hcs_to_stored_scenes=False`.
- Centralized full-resolution dimension bounds and exact non-spatial indices in
  `CziDimensions`.
- Added PySide6 to the `[all]` and `[omezarr-gui]` extras and improved the
  missing-Qt installation guidance.

## Fixes

- Fixed stage-position extraction for ordinary CZI files whose physical
  subblocks carry an `S=0` coordinate without semantic scene metadata.
- Updated the Voronoi-Otsu segmentation notebook to select scene-based reads
  from `CziMetadata.has_scenes`.

## Installation

Install the core package:

```bash
python -m pip install --upgrade czitools
```

Install the OME-Zarr GUI and its Qt binding:

```bash
python -m pip install --upgrade "czitools[omezarr-gui]"
```

The GUI installation also provides both console commands:

```bash
czitools-omezarr-gui
czi_hcs_check --help
```
