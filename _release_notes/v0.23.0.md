# czitools v0.23.0

Release date: 2026-08-28

## Highlights

- **OME-ZARR GUI improvements**: Unified single-file `.ozx` checkbox for both HCS
  and non-HCS conversions, automatic metadata loading, and improved Scene ID
  visibility controls.
- **Enhanced HCS support**: Improved handling of variable well field counts and
  scene shape tolerance; new `czi_hcs_check` CLI for plate inspection.
- **ngff-zarr compatibility**: Fixed compressor codec selection for zarrista
  compatibility layer to ensure valid OZX archive generation.
- **Bug fixes**: Resolved 3D rendering issues, multiscale handling, pyramid level
  constraints, and non-pyramid bounds enforcement for regular 6D reads.

## OME-ZARR Converter GUI

The experimental converter now features:
- **Automatic metadata loading** when a file is selected
- **Conditional HCS mode**: "Write HCS layout" appears only for detected plate files
- **Scene ID selector**: Visible only for multi-scene, non-HCS images
- **Single `.ozx` option**: One checkbox for both HCS and non-HCS archive output
- **Improved logging**: Real-time conversion progress in scrollable panel
- **Optional napari integration**: View results directly in napari viewer

## ngff-zarr & Codec Handling

Fixed compressor object construction to use canonical `numcodecs.Blosc` and
`numcodecs.Zstd` objects, ensuring compatibility with ngff-zarr's zarrista
layer for both directory and OZX output paths.

## HCS Plate Inspection

The `czi_hcs_check` CLI tool provides rich-formatted terminal output for
well-plate metadata:
- Plate overview (rows, columns, fields per well)
- Well-by-well field listings with scene indices
- Optional suppression of summary table (`--no-well-table`)
- Filtering by well name (`--well B4`)

## Compatibility

- Python 3.12 and 3.13
- ngff-zarr ≥ 0.45.0
- ome-zarr ≥ 0.16.0
- No intentional breaking API changes

## Installation

```bash
python -m pip install --upgrade "czitools==0.23.0"
```

## Export GUI Quick Start

```bash
pip install "czitools[omezarr-gui]"
czitools-omezarr-gui
```

Or from the repository:

```bash
pixi run omezarr-gui
```
